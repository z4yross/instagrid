v1 spec (V1-V76, T1-T153, B1-B103) lives in git history: `main@2ef5b8c:SPEC.md`. Ids here restart; cite v1 ids as `v1.Vn`.

## §G — Goal

Rebuild browser-only Instagram feed planner from scratch: arrange image blocks on 3-col 3:4 grid, join/split blocks for more grid combos, export numbered 1080×1350 cells. v1 feature set done right + join/split + preview, desktop and mobile equal.

## §V — Invariants

### Domain

| id  | invariant                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| V1  | Blocks never overlap. Every mutation (move, resize, join, split, paste, upload) validated in I.core; invalid result rejected, state unchanged.                                                                                                                                                                                                                                                                                                                                                               |
| V2  | Block rect = integer cells. col ∈ [0,2], colSpan ∈ [1,3], col+colSpan ≤ 3, row ≥ 0, rowSpan ≥ 1.                                                                                                                                                                                                                                                                                                                                                                                                             |
| V3  | Image transform stored viewport-independent: pan = offset of image center from frame center as fraction of frame width/height (screen axes, not rotated), zoom = multiplier over cover-fit scale (zoom 1 fills frame; below 1 shows bars color), rotation in {0,90,180,270}, flipX, flipY. Never pixels.                                                                                                                                                                                                     |
| V4  | One geometry function maps (block, frame, transform) → image draw rect. Screen render and export both call it. Export of a cell = pixel match of what grid shows in that cell.                                                                                                                                                                                                                                                                                                                               |
| V5  | Block has `frame` {cols, rows, col, row}: image laid out over virtual cols×rows cell area, block shows sub-rect starting at (col,row). Unsplit block: frame = own span, offset 0,0.                                                                                                                                                                                                                                                                                                                          |
| V6  | Split: block spanning N cells → N 1×1 blocks, same imageId + transform, frame = original span, offset = cell index. Picture on grid identical before/after split.                                                                                                                                                                                                                                                                                                                                            |
| V7  | Join: selection whose union is a full rectangle with no foreign blocks inside → one block over that rect. Pieces of same split (same imageId + frame + transform, offsets match positions) → exact reverse of V6, no new image. Otherwise → composite: selection rendered as shown (via V4 geometry, 1080×1350 per cell, color cells included) into a NEW image stored in library; resulting block uses it with identity transform. Source images stay in library. Grid picture identical before/after join. |
| V8  | Join/split are single undo steps. Disabled with reason shown when preconditions fail.                                                                                                                                                                                                                                                                                                                                                                                                                        |
| V9  | Upload numbering = right-to-left per row, bottom-to-top. Only cells holding image content numbered, from 1. Placeholders + empty cells skipped.                                                                                                                                                                                                                                                                                                                                                              |
| V10 | Grid shows min 3 rows; grows when content reaches last row; trailing empty rows trimmed, never below content.                                                                                                                                                                                                                                                                                                                                                                                                |
| V11 | New/re-added blocks land on first free cell, scan left→right, top→bottom. Batch upload places each on distinct cell.                                                                                                                                                                                                                                                                                                                                                                                         |
| V12 | Placeholder (color cell) = solid color, no image, never exported, never numbered.                                                                                                                                                                                                                                                                                                                                                                                                                            |
