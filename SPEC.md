# SPEC — InstaGrid v2 (remake)

Status: SHIPPED 2026-11-26. v2 is live at instagrid.z4yross.com (PR #1). Further work goes through new branches and PRs.
v1 spec (V1-V76, T1-T153, B1-B103) lives in git history: `main@2ef5b8c:SPEC.md`. Ids here restart; cite v1 ids as `v1.Vn`.
Companion docs: `PRODUCT.md` (product truth), `DESIGN.md` (visual system), `design/mockups/remake.html` (approved mockup), `design/mockups/remake-decisions.md` (owner decisions, verbatim).

## §G — Goal

Rebuild browser-only Instagram feed planner from scratch: arrange image blocks on 3-col 3:4 grid, join/split blocks for more grid combos, export numbered 1080×1350 cells. v1 feature set done right + join/split + preview, desktop and mobile equal.

## §V — Invariants

### Domain

| id  | invariant                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| V1  | Blocks never overlap. Every mutation (move, resize, join, split, paste, upload) validated in I.core; invalid result rejected, state unchanged.                                                                                                                                                                                                                                                                                                                                                               |
| V2  | Block rect = integer cells. col ∈ [0,2], colSpan ∈ [1,3], col+colSpan ≤ 3, row ≥ 0, rowSpan ≥ 1.                                                                                                                                                                                                                                                                                                                                                                                                             |
| V3  | Image transform stored viewport-independent: pan = offset of image center from frame center as fraction of frame width/height (screen axes, not rotated), zoom = multiplier over cover-fit scale (zoom 1 fills frame; below 1 shows bars color), rotation in {0,90,180,270}, flipX, flipY. Never pixels.                                                                                                                                                                                                     |
| V4  | One geometry function maps (block, frame, transform) → image draw rect. Screen render and export both call it. Export of a cell = pixel match of what grid shows in that cell.                                                                                                                                                                                                                                                                                                                               |
| V5  | Block has `frame` {cols, rows, col, row}: image laid out over virtual cols×rows cell area, block shows sub-rect starting at (col,row). Unsplit block: frame = own span, offset 0,0.                                                                                                                                                                                                                                                                                                                          |
| V6  | Split: block spanning N cells → N 1×1 blocks, same imageId + transform, frame = original span, offset = cell index. Picture on grid identical before/after split.                                                                                                                                                                                                                                                                                                                                            |
| V7  | Join: selection whose union is a full rectangle with no foreign blocks inside → one block over that rect. Pieces of same split (same imageId + frame + transform, offsets match positions) → exact reverse of V6, no new image. Otherwise → composite: selection rendered as shown (via V4 geometry, 1080×1350 per cell, color cells included) into a NEW image stored in library; resulting block uses it with identity transform. Source images stay in library. Grid picture identical before/after join. |
| V8  | Join/split are single undo steps. Disabled with reason shown when preconditions fail.                                                                                                                                                                                                                                                                                                                                                                                                                        |
| V9  | Upload numbering = right-to-left per row, bottom-to-top. Only cells holding image content numbered, from 1. Placeholders + empty cells skipped.                                                                                                                                                                                                                                                                                                                                                              |
| V10 | Grid shows min 3 rows; grows when content reaches last row; trailing empty rows trimmed, never below content.                                                                                                                                                                                                                                                                                                                                                                                                |
| V11 | New/re-added blocks land on first free cell, scan left→right, top→bottom. Batch upload places each on distinct cell.                                                                                                                                                                                                                                                                                                                                                                                         |
| V12 | Placeholder (color cell) = solid color, no image, never exported, never numbered.                                                                                                                                                                                                                                                                                                                                                                                                                            |

### Transfer between devices

| id  | invariant                                                                                                                                                                                                                                                                                                                              |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| V45 | "Add photos from your phone": a device shows a QR code with a one-time link; a second device that opens it sees a send page (not the editor), chooses photos, and they arrive in the first device's library and on its grid (first free cells). | V46 | The link carries a random one-time address (~124 bits) created when the dialog opens. | V47 | Photos travel over an encrypted WebRTC data channel between the two devices. | V48 | Everything received is untrusted: messages are shape-checked; only JPG / PNG / WEBP, at most 40 MB each and 60 per session; chunks must arrive in order and never exceed the announced size; file names are stripped of paths and control characters. ### Symmetry patterns

| id  | invariant                                                                                                                                                                                                                                                                                                                                           |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| V50 | Symmetry editor: a photo is placed under N mirror lines (1..12) that all pass through the middle of the result. They cut it into 2N wedges; the first shows the photo, the others its reflections. 1 line = mirror, 2 = four-way, 3+ = kaleidoscope. The line angle is adjustable. One drawing routine paints the live preview and the saved image. |
| V51 | It is its own full-screen screen, opened from a selected photo (inspector on desktop, action bar on mobile) and from any photo in the library. The main editor gains no panel.                                                                                                                                                                      |
| V52 | In the editor: drag the preview to move the photo under the lines, wheel or pinch to zoom, slider to turn it; arrow keys nudge. Result size is chosen in grid cells (1..3 columns, 1..4 rows) and rendered at 1080×1440 px per cell. Saving a new pattern adds it to the library and places it on the grid as one block of that size.               |
| V53 | The recipe (source photo, lines, angle, size, position, zoom, turn) is stored with the image. A pattern opens again with its recipe; saving replaces the image in place, so every block that shows it, in every grid, updates. If the source photo was deleted the pattern stays as an ordinary image and a new pattern can be made from it.        |
| V54 | The photo always covers the whole result: no empty area. A move stops at the photo's edge and slides along it; zooming out, turning, changing the lines or the size zooms the photo in just enough when it would otherwise open a gap. Checked against every wedge's slice of the rectangle, not only the first.                                    |
| V55 | The mirror lines can be shown over the preview while editing; they are never part of the saved image.                                                                                                                                                                                                                                               |
| V56 | Symmetry editor: both angle controls (line angle, photo turn) keep their slider and also have minus / plus buttons that change the angle by exactly one degree, wrapping around the full turn. A step that would uncover the result is refused like any other change (V54).                                                                         |
